## 二、欧路词典 Eudic（主参照：桌面 + 手机双形态）

### 2.1 桌面端（macOS 客户端）

#### 图 1 · 查词主窗
![欧路桌面·查词主窗](assets/eudic-desktop-01-main-lookup.png)
来源：App Store「Eudic 欧路词典」macOS 版官方截图（Apple CDN 800×500 原图）。

- **布局**：三栏。左栏=词典分组树（权威词典/扩充词库，可折叠）；中栏=词条详情（词头+音标+释义+例句+词组+近义联想+笔记，分区折叠）；右栏=生词本/学习面板。顶栏=搜索框+模式切换。
- **色彩**：浅色主题，白底+浅灰分区，蓝色高亮选中项，整体低饱和、大量留白。
- **信息密度**：中栏高（一屏多分区折叠），左右栏低。密度靠「折叠分区」而非「缩小字号」控制。
- **导航**：左栏切词典、中栏内折叠分区、顶栏搜索。层级清晰，无模态打断。
- **可借鉴**：① 中栏「词头+音标+多分区折叠」的详情组织方式 → 落到 unidict 桌面**结果页 EntryResultsPane**（现已有词典折叠分组，可再加分区内小节折叠）；② 右栏常驻生词本/学习面板 → 落到 unidict 桌面**侧栏生词本 tab**（现是 tab 切换，可考虑窄屏常驻预览）；③ 左栏词典分组树 → 落到 unidict **词典管理/分组**。
- **不适用**：右栏「学习记录+图表」属欧路的自研学习体系（进度/熟练度统计），unidict 定位离线查询、无学习进度产品，**不引入**（roadmap §A 已弃学习统计/成就）。

#### 图 2 · 词典管理（扩充词库）
![欧路桌面·词典管理](assets/eudic-desktop-02-dict-manage.png)
来源：同上（App Store macOS 版官方截图）。

- **布局**：左栏分组树 + 右栏词典列表（复选框勾选启用/停用），顶部「管理」入口。
- **色彩**：浅色，选中行浅蓝底，复选框蓝勾。
- **信息密度**：低，列表式，一行一词典。
- **导航**：左栏切分组、右栏勾选。
- **可借鉴**：① 「复选框启用/停用词典」的轻量管理 → 落到 unidict **设置抽屉「词典」tab / gui 工具栏分组下拉**（现已有优先级/分组，可加启用开关）；② 分组树与列表联动 → unidict 已有分组，可补树形可视化。
- **不适用**：欧路的「扩充词库下载」是在线商店，unidict 离线优先、无在线商店（P-10 gated），**不引入**。

#### 图 3 · 生词本（表格视图）
![欧路桌面·生词本](assets/eudic-desktop-03-vocab-table.png)
来源：同上（App Store macOS 版官方截图）。

- **布局**：表格式生词本，列=单词/释义/添加时间/熟练度，行内可操作；图中有右键/悬浮操作浮层（深色小浮窗）。
- **色彩**：浅色，表头浅灰，悬浮浮层深色（对比突出）。
- **信息密度**：中，表格紧凑但不拥挤。
- **导航**：表格排序+筛选+行内操作。
- **可借鉴**：① 「单词+释义+添加时间+熟练度」多列表格 → 落到 unidict 桌面**生词本**（现是卡片式，可补表格视图切换，便于批量浏览）；② 行内悬浮操作浮层 → unidict 卡片上已有「+标签/笔记」轻动作，可补行内快捷操作。
- **不适用**：「熟练度」列属欧路学习体系，unidict 无此概念，**不引入**该列。

#### 图 4 · 单词卡片（记忆/复习）
![欧路桌面·单词卡片](assets/eudic-desktop-04-word-card.png)
来源：同上（App Store macOS 版官方截图）。

- **布局**：居中大字卡：词头+音标+词性+释义，底部「认识/模糊/忘记」三档按钮，顶部进度条。
- **色彩**：浅色卡片+蓝色主按钮，大量留白，聚焦单字。
- **信息密度**：极低，一屏一词。
- **导航**：底部三档自评驱动翻页。
- **可借鉴**：① 「认识/模糊/忘记」三档自评的极简卡片 → unidict 定位离线查询，**复习/遗忘曲线已按 §A 放弃**，但若未来要做轻量复习，此三档是最简范式；② 大字留白的卡片美学可借到 unidict **结果页词条卡头**（现卡头已升级，可再强化词头视觉层级）。
- **不适用**：整套「背单词/复习」流程与 unidict 定位冲突（§A），**不引入**。

#### 图 5 · 鼠标自动取词（浮窗）
![欧路桌面·鼠标取词](assets/eudic-desktop-05-hover-popup.png)
来源：同上（App Store macOS 版官方截图）。

- **布局**：文档/网页之上悬浮小窗：词头+音标+释义+发音按钮+「加入生词本」，半透明深色，贴光标。
- **色彩**：深色半透明浮层，与底层文档形成对比。
- **信息密度**：低，只给核心释义。
- **导航**：浮窗内轻操作（发音/收藏），失焦即收。
- **可借鉴**：① 贴光标小浮窗+半透明深色+核心释义 → 直接对标 unidict **悬浮取词窗 QuickLookupPane**（已交付，可对照优化信息层级：词头/音标/释义/发音/生词本的排布）；② 半透明深色在浅色文档上的可读性处理。
- **不适用**：欧路取词触发是「鼠标悬停自动取词」，unidict 是剪贴板/热键取词（悬停已按 §A 放弃），**触发方式不引入**，仅借鉴浮窗视觉。

#### 图 6 · AI 大模型翻译
![欧路桌面·AI翻译](assets/eudic-desktop-06-ai-translate.png)
来源：同上（App Store macOS 版官方截图）。

- **布局**：左右分栏（左输入/右输出），顶栏风格选择，底部输入区。
- **色彩**：浅色，左右栏用浅灰底区分。
- **信息密度**：中，双栏对照。
- **导航**：顶栏切换翻译风格/术语库。
- **可借鉴**：① 「左输入右输出」双栏对照 → unidict 已有 AI 外部命令桥（UNIDICT_AI_CMD），若做可视化可参考双栏；② 「自定义翻译风格/术语库」概念 → unidict AI 桥可暴露「风格」参数。
- **不适用**：在线大模型翻译需 provider 鉴权/基建（roadmap LLM 集成 deferred），unidict 走**本地外部命令桥**，**在线大模型不引入**。

## 三、GoldenDict-ng（桌面对照：纯桌面，无手机 App）

> **市场结论**：GoldenDict-ng 是开源桌面词典，**只有桌面客户端，没有手机 App**。这说明「词典」品类里存在一批纯桌面、面向重度查询/翻译用户的工具型产品，与 unidict 的「离线查询」定位更接近，是比欧路更合适的桌面参照。

#### 图 1 · Windows 亮色主窗
![GoldenDict·Windows亮色](assets/goldendict-desktop-01-win-light.webp)
来源：GoldenDict-ng 官方文档站 img/gd_windows_white.webp（项目官方 hero 图）。

- **布局**：经典桌面三栏——顶栏菜单（File/View/Edit/Search/History/Favorites/Help）+工具栏（词典选择+搜索+多种查词模式图标）；左=词条详情（编号释义+音标+发音按钮+例句+出处+用法注）；右=Found in dictionaries（命中词典列表）+Favorites+History（2/500）。
- **色彩**：亮色，白底+黑字，链接蓝色，工具栏彩色图标。
- **信息密度**：高，一屏多栏多分区，但靠分栏而非缩字号。
- **导航**：顶栏菜单+工具栏、左栏详情、右栏命中/收藏/历史。层级偏多（传统桌面应用）。
- **可借鉴**：① 「Found in dictionaries」右栏**显示命中了哪些词典** → 落到 unidict 结果页（现按词典折叠分组，可补「命中词典」概览chip）；② History 显示「2/500」**计数** → unidict 历史可补计数；③ 多种查词模式图标化 → unidict 模式下拉可考虑图标辅助。
- **不适用**：① 顶栏多级菜单（File/Edit/View…）是传统桌面范式，unidict 用侧栏+抽屉更现代，**不引入**菜单栏；② 右栏 Favorites/History 常驻占空间，unidict 用 tab 更省，**不引入**。

#### 图 2 · macOS 暗色主窗
![GoldenDict·macOS暗色](assets/goldendict-desktop-02-mac-dark.webp)
来源：GoldenDict-ng 官方文档站 img/gd_mac_black.webp。

- **布局**：与图 1 同构（工具栏+左详情+右命中），但暗色主题；多 Tab（architecture/Apple/mac）切换已打开词条。
- **色彩**：暗色，深灰底+浅字，链接亮蓝，整体高对比。
- **信息密度**：高。
- **导航**：Tab 切换词条 + 工具栏。
- **可借鉴**：① **暗色主题**的对比度处理（链接亮蓝、正文浅灰）→ unidict 已有跟随系统亮暗，可对照暗色可读性；② 多 Tab 打开多词条 → unidict 结果页可考虑多词条 Tab。
- **不适用**：暗色目前 unidict 已支持（跟随系统），无需额外引入。

#### 图 3 · Linux 亮色 + 搜索建议 + 中文词典
![GoldenDict·Linux搜索建议](assets/goldendict-desktop-03-linux-search.webp)
来源：GoldenDict-ng 官方文档站 img/gd_linux_genshin.webp。

- **布局**：同主窗，但搜索框激活时弹出**搜索建议下拉**（hello/Hello/HELLO/你好/hello baby/… 分组：词典命中+建议）；右栏 Found in dictionaries 显示 WordNet/维基百科；左栏中文词典释义（维基词典）。
- **色彩**：亮色，建议下拉白底+分组标题灰。
- **信息密度**：高。
- **导航**：搜索建议下拉+分组。
- **可借鉴**：① **搜索建议下拉**（输入即提示，分组：精确命中/前缀/建议）→ 落到 unidict 搜索框（现已有建议，可对照分组与排版）；② 中文维基词典的中英混排渲染。
- **不适用**：无特别不适用。

#### 图 4 · Dictionaries 管理对话框（Sources 标签）
![GoldenDict·词典管理](assets/goldendict-desktop-04-dict-dialog.webp)
来源：GoldenDict-ng 官方文档站 manage_sources 页内嵌图 img/dict_file_tab.webp。

- **布局**：对话框，顶部 Sources/Dictionaries/Groups 三标签；Sources 下 Files/SoundDirs/Morphology/Wikipedia/Websites/DICT servers/Programs 子标签；主体=搜索路径列表（Path+Recursive 复选），Add/Remove 按钮，Rescan now。
- **色彩**：亮色，表格+复选框。

## 五、三家横向对照

| 维度 | 欧路词典 Eudic | GoldenDict-ng | MDict | unidict 现状 |
|---|---|---|---|---|
| 形态 | 桌面+手机 | 仅桌面 | 桌面+手机 | 桌面(QML)+手机(Android壳) |
| 桌面布局 | 三栏（词典树/详情/学习） | 三栏（菜单/详情/命中+历史） | 官网无纯净图 | 侧栏+结果面板（词典折叠分组） |
| 手机布局 | 搜索+分区详情+底Tab | — | 搜索+分区详情+底Tab | 单页查词+词本 |
| 色彩 | 浅色为主，低饱和 | 亮/暗双主题 | 浅色 | 跟随系统亮暗 |
| 信息密度 | 中（折叠分区） | 高（多栏多分区） | 极高（塞满） | 中（折叠分组） |
| 查词触发 | 搜索+鼠标取词浮窗 | 搜索+工具栏多模式 | 搜索 | 搜索+剪贴板/热键+悬浮窗 |
| 词典管理 | 复选框启用+分组树 | 源路径+重扫+信息面板 | 复选框启用 | 优先级/分组+环境变量/扫描 |
| 笔记/高亮 | 荧光笔高亮 | — | — | 纯文本/Markdown |
| 学习体系 | 有（背单词/熟练度/进度） | 无 | 无 | 无（§A 已弃） |
| 在线商店 | 有（扩充词库） | 无 | 无 | 无（P-10 gated） |

**关键结论**：
- **欧路**是「词典+学习」综合体，视觉最现代、最干净，但大量功能（学习进度/背单词/在线商店/AI大模型）与 unidict 定位冲突，**只借视觉与交互，不借功能**。
- **GoldenDict** 是纯工具型桌面词典，与 unidict 定位最接近，其**命中概览/搜索建议/词典源管理/元信息面板**最值得借鉴。
- **MDict** 手机端的**配图/搜索建议分组/词典勾选**可借；桌面端无纯净截图，不作参照。
- **GoldenDict 无手机 App** 说明词典品类存在纯桌面工具层，unidict 桌面端可安心做「工具型」而不必强求全功能。

- 学习进度/熟练度/背单词/遗忘曲线复习（§A 已弃）。
- 在线词典商店/扩充词库下载（P-10 gated，离线优先）。
- AI 大模型在线翻译（需 provider 基建；unidict 走本地外部命令桥）。
- 鼠标悬停自动取词（§A 已弃；unidict 用剪贴板/热键）。
- 传统桌面菜单栏（unidict 侧栏+抽屉更现代）。

### 6.4 建议实施顺序（过目后）

1. **低成本高收益**（先做）：结果页分区折叠、命中词典 chip、搜索建议分组、历史计数。
2. **中成本**：生词本表格视图、词典元信息面板、笔记荧光笔、暗色对比度校验。
3. **手机端**：查词页笔记 Tab + 配图强化、词典勾选管理。
4. **取词浮窗**：QuickLookupPane 视觉对照优化。
