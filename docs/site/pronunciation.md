# 发音

## 本地 TTS（已上线）

- **桌面**：查词结果与生词本卡片一键朗读（🔊），支持音色/语速/音调/音量调节、自动发音（查到即读）与语音预设；剪贴板取词+全局热键联动发音
- **Android**：系统 TextToSpeech 引擎朗读，卡片 ▶ 一键播；引擎缺失/初始化失败不挡其余功能（状态行 `M4-TTS-READY` / `M4-TTS-FAIL` 供诊断）

本地合成零网络请求——发音不外发任何内容。

## 在线「全球发音」（规划中）

计划接入在线词典发音服务（真实人声、分英音/美音口音可选），设计口径遵循既定隐私默认：

- **默认关闭**：要用在线发音，需在设置里显式开启
- **开启时明示发送内容**：只把查询词发给发音服务，不带历史/生词本
- 发音源可切换（本地 TTS / 在线 / 自动回落），接口层 `PronunciationSource` 预留可扩展

上线前此功能不会出现在任何分发包里；落地后本页更新各家接口与口音清单。

## 发音评分（实验性）

本地离线发音评分（M3）：onnxruntime 声学模型 + CTC 强制对齐 + GOP 逐音素打分，供跟读练习。构建开关、模型下载与用法见 [docs/pronunciation-plan.md](https://github.com/cuihairu/unidict/blob/main/docs/pronunciation-plan.md)（模型约 635MB，不随包分发）。
